# Checklist

## Before the pool

- [ ] The buyer, their size and what they use today are written down.
- [ ] Calls are split into numbered turns and speakers are re-judged.
- [ ] If there are no calls, the set says `hypothesis only`.

## The pool

- [ ] Every row has an id, a source, a voice and a verbatim quote.
- [ ] A script confirmed every quote against its saved source.
- [ ] Vendors and the company's own people are not askers.
- [ ] Every row has a grade and a fit tag. Nothing was deleted.

## The gap check

- [ ] Prompts do not name the company.
- [ ] Every assistant answered. A failed engine was re-run.
- [ ] Every answer has one of four marks and a carrier.

## The review

- [ ] The reviewer did not write the rows and had a fresh context.
- [ ] Fixes are applied. Cross-group fixes are done by hand.

## The freeze

- [ ] Persona, role and segment tags exist for every question.
- [ ] Counts by segment and role were read before the freeze.
- [ ] Brand questions and controls are labelled groups.
- [ ] The README states the no-edit rule and the 10% rule.

## The maps

- [ ] The answer map routes every leftover question.
- [ ] The coverage map has a page, `missing` or `planned` on every row.
- [ ] No page was widened to fit a single question.
