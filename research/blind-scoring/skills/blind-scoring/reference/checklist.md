# Checklist

## Before scoring

- [ ] Each run has two or more versions, and no two are identical.
- [ ] The rubric and its version are written down before any text is read.
- [ ] Each run has its own random order.
- [ ] `key.json` exists and is outside the scorer's reach.
- [ ] No file name, metadata or first line shows the version.

## Scoring

- [ ] One fresh scorer per run.
- [ ] The scorer got only the blind files and the rubric.
- [ ] Scores were kept as given. Reruns are recorded.

## Report

- [ ] The reveal happened after all scores were in.
- [ ] Every run has its own row.
- [ ] The mean and the difference from the original are shown.
- [ ] n, scorers per text and the rubric are stated.
- [ ] The report says what the sample can and cannot show.
- [ ] Any tell that may break the blinding is noted.
