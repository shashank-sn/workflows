# Checklist

## Before writing

- [ ] The audit of the place exists, and every drafted line has a source.
- [ ] The live place was read signed out, and each read has a date.
- [ ] The best examples were read the same day.

## The full page

- [ ] Sections are in the order of `process.md`.
- [ ] Every change has type, where, link, who, paste (or why none), why and done when.
- [ ] Each decision quotes its text and carries a recommendation.
- [ ] The verdict is one of needed, low priority, not needed, with evidence.
- [ ] Every number has a cleared source. Unsourced claims are flagged, not pasted.

## The founders' page

- [ ] Every paste matches the full page byte for byte.
- [ ] Changes are grouped by where they happen.
- [ ] Each founder has a "your part" box with their changes and time.
- [ ] No internal words, no hedging, no recurring work.
- [ ] Every link opens. A sign-in page is fine.
- [ ] "After the changes" has a desktop check and a phone check.
- [ ] Every "above", "below" and step number still points at the right place.

## The appendix

- [ ] Before and after views match the changes page.
- [ ] Assistant counts come from stored, dated answers, or the file says "No stored answers yet".
- [ ] It links only public pages.

## Hand over

- [ ] The cold read ran and its fixes are in.
- [ ] No file was published, sent or submitted.
- [ ] The hand-over lists what could not be confirmed.
