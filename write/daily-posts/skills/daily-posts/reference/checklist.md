# Checklist

## Questions

- [ ] At most 3 questions.
- [ ] Each question has a linked source.
- [ ] Each question asks for one story, number or moment.
- [ ] No repeat of an earlier question or angle.

## Drafts

- [ ] Each answer is saved word for word.
- [ ] Two drafts per answer: one in the person's order, one from a different entry point.
- [ ] The phrase list covers every phrase not from the answer.
- [ ] No take, fact or number that is not in the answer.

## Editor

- [ ] Each draft ran through the editor before the person saw it.
- [ ] Each rewrite that added a claim was reverted.
- [ ] The result records passed, or no more gain. A pass is never claimed without a run.

## Approval and schedule

- [ ] The person sent a letter for the exact draft.
- [ ] Typo fixes are named as old to new.
- [ ] Unapproved siblings are marked dropped, not deleted.
- [ ] The slot is free, in the future and in the person's time zone.
- [ ] No post-now mode was used.
- [ ] No reply, like, follow or direct message was sent.
